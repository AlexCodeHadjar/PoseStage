# Проверка PoseStage — 20 октября 2026

Готовая поставка: `dist\PoseStage.exe` и находящаяся рядом папка `WebView2`.
Исходники, закреплённые зависимости, локальные аддоны Three.js и лицензии включены в проект.
Краткие результаты и SHA-256 EXE: `validation.json`.

## Выполнено

- Собран Windows x64 EXE через PyInstaller: onefile, windowed, с иконкой и всей папкой `web` внутри.
- Проверка `PoseStage.exe --self-check` выполняется без Python и без окна: локальные библиотеки,
  WebView2 Runtime и каталог поз. Проверка содержимого архива EXE также сравнивает все файлы
  `web` с исходниками по SHA-256.
- Шесть Python-тестов прошли: альфа `>8`, фильтрация имён и битых PNG, чтение из кэша только
  изменившихся файлов, восстановление повреждённого кэша, состояние и приоритет папок,
  HTTP allowlist, запрет обхода путей, Windows drive/UNC-путей и постороннего Host.
- Найдено 220 поз. Границы и масштаб всех 220 проверены при 1920×1080, 1280×1024,
  3440×1440 и 1080×1920; дополнительно — 960×540 и возврат к 1920×1080.
  В каждом формате проверены 48 897 опорных точек при трёх положениях камеры:
  они находятся внутри крышки с запасом от края, опорная область центрирована по её
  видимому эллипсу. Теневой контур касается реальной верхней плоскости; максимальная
  численная погрешность меньше 0,000001 единицы сцены. Восемь примеров, включая
  три проблемные позы со скриншотов пользователя, проверены графическим рендерером.
- Два последовательных прохода по всем 220 позам завершились успешно. Кэш поз — не более 7 текстур. GPU-счётчики стабилизировались: 24 текстуры сцены вместе с буферами
  постобработки, 15 геометрий и 21 программа; во втором проходе роста не было.
- Переходы с растворением и совпадающим теневым шейдером компилируются без ошибок.
  Проверены закольцовка, серия из 80 быстрых нажатий, отсутствие хвоста очереди,
  сохранение индекса и остановка рендера при неактивности.
- Цвета проверены на 685 непрозрачных точках исходного PNG, включая 469 серых:
  медианная разница RGB — 0, 95-й перцентиль — 1, максимум — 1 из 255. Разница в пределах
  интерполяции текстуры. AgX, bloom, зерно и виньетка через фигуру не проходят.
- Проверены ←/→, A/D, HTML-стрелки, вызовы F/F11/Esc, игнорирование колеса,
  скрытие и появление курсора/стрелок. При DPI 150% canvas имеет 2880×1620 физических
  пикселей для окна 1920×1080 CSS-пикселей; уменьшение разрешения студии не уменьшает
  разрешение фигуры.
- В автоматическом прогоне страница не сделала ни одного внешнего сетевого запроса.
  Все ассеты локальные; production WebView2 дополнительно ограничен локальным прокси
  и блокировкой внешних запросов/переходов.
- Список, размеры и времена изменения всех исходных файлов в папке поз сверены
  до и после работы. Изменений нет; позы в поставку не копировались.

## Оптимизация

Прозрачные поля PNG исключены из геометрии через bbox/UV без изменения самого изображения.
У неподвижной фигуры отключён расчёт процедурного шума. Теневой дубль не читает текстуру
в цветовом проходе, но сохраняет её в настоящем depth-проходе. Карта теней обновляется
по необходимости, а не безусловно каждый кадр. Постобработка ограничена 1080p, адаптивно
снижает своё разрешение и отключает bloom при недостаточном FPS. Фигура остаётся в
разрешении canvas с учётом DPI. Предзагрузка ограничена соседями; удаляемые текстуры,
материалы и геометрии освобождаются. Неактивное окно прекращает рендер.

## Ограничения проверки и отличия

1. По уточнению пользователя исправлена исходная формула размещения: центрируется
   опорная область вместо всего bbox, а опора определяется нижним контуром вместо
   единственной нижней точки. Широкие и сидячие позы уменьшаются до помещения опор
   на крышке. Рисунок выводится плоским ортографическим проходом; перспективная камера
   используется для студии и теней. Для текущих 220 файлов группы опоры проверены по
   миниатюрам; новые позы используют автоматическую группу, требующую визуальной проверки.
2. **Аппаратные 60 FPS на Intel Iris Xe / Radeon Vega не подтверждены.** Фоновые графические
   проверки выполнялись в Chromium со SwiftShader — программным рендерером. Это позволяет
   проверить изображение, шейдеры и освобождение ресурсов, но не скорость вашей видеокарты.
   Показатель `fps` до накопления измерений не является результатом аппаратного теста.
3. **Холодный запуск EXE до видимой первой позы за 2 секунды не подтверждён.** Он включает
   подготовку текстуры, распаковку
   PyInstaller, системная проверка EXE и показ первого GPU-кадра. Повторный каталог берётся
   из кэша. Отдельной чистой Windows 11 для проверки двойным кликом не было.
4. Системный WebView2 в доступном окружении возвращал ошибку инициализации. Поэтому рядом
   с EXE поставлен официальный **Fixed Version Runtime 155.0.4283.62 x64**. Он не устанавливается
   в Windows, работает без сети и добавляет около 705 МБ к размеру папки. Сам EXE — около 20 МБ.
   Если автономная папка отсутствует, приложение использует установленный системный Runtime.
5. Необязательное отражение в полу отключено. Свет, скруглённый подиум, environment,
   контактная тень и настоящая тень силуэта реализованы.

Приложение не открывалось повторно поверх рабочего стола после остановки пользователем
проверки через Computer Use; последующие тесты и проверка EXE выполнялись фоном.
